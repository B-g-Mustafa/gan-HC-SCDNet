# Stable Diffusion Fine-tuning for Style Transfer

Fine-tuning scripts for training SD models on 60k synthetic style-transferred images with VLM captions.

## Training Scripts

All scripts train for **20 epochs** with **WandB monitoring** on the complete captioned dataset.

### 1. **SD 1.5 LoRA** (`train_sd15_lora.py`)
- Base model: `runwayml/stable-diffusion-v1-5`
- Method: LoRA (rank=16, alpha=32)
- Resolution: 512x512
- Batch size: 4 (effective=16 with grad accumulation)
- Output: `/home/msai/birul001/BIRUL001/models/sd15_lora`

### 2. **SD 3.5 Large LoRA** (`train_sd35_lora.py`)
- Base model: `stabilityai/stable-diffusion-3.5-large`
- Method: LoRA (rank=32, alpha=64) - MMDiT transformer
- Resolution: 1024x1024
- Batch size: 2 (effective=16)
- Uses 3 text encoders (CLIP-L, CLIP-G, T5)
- Output: `/home/msai/birul001/BIRUL001/models/sd35_lora`

### 3. **SD 1.5 + ControlNet** (`train_sd15_controlnet.py`)
- Base model: `runwayml/stable-diffusion-v1-5`
- Method: LoRA on UNet + ControlNet training
- Conditioning: Content images guide style transfer
- Resolution: 512x512
- Batch size: 3 (effective=15)
- Output: `/home/msai/birul001/BIRUL001/models/sd15_controlnet`

### 4. **SD 2.5 + ControlNet** (`train_sd25_controlnet.py`)
- Base model: `stabilityai/stable-diffusion-2-1`
- Method: LoRA on UNet + ControlNet training
- Conditioning: Content images guide style transfer
- Resolution: 768x768
- Batch size: 2 (effective=16)
- Output: `/home/msai/birul001/BIRUL001/models/sd25_controlnet`

## Dataset

**Path:** `/home/msai/birul001/BIRUL001/dataset/`
- **CSV:** `captioned_metadata/complete_captioned_metadata.csv`
- **Samples:** 60,000 synthetic style-transferred images
- **Captions:** Generated by Qwen2-VL-7B (content + style descriptions)
- **Structure:**
  - `content_path`: Original COCO image
  - `style_path`: WikiArt style reference
  - `synthetic_path`: Style-transferred result
  - `final_caption`: Combined VLM caption

## Usage

### Run Training

```bash
# SD 1.5 LoRA
python train_sd15_lora.py

# SD 3.5 LoRA
python train_sd35_lora.py

# SD 1.5 + ControlNet
python train_sd15_controlnet.py

# SD 2.5 + ControlNet
python train_sd25_controlnet.py
```

### SLURM Submission

```bash
# Create SLURM scripts
sbatch --job-name=sd15-lora --wrap="python train_sd15_lora.py"
sbatch --job-name=sd35-lora --wrap="python train_sd35_lora.py"
sbatch --job-name=sd15-cn --wrap="python train_sd15_controlnet.py"
sbatch --job-name=sd25-cn --wrap="python train_sd25_controlnet.py"
```

## WandB Monitoring

Each script logs to WandB with:
- **Project names:**
  - `style-transfer-sd15-lora`
  - `style-transfer-sd35-lora`
  - `style-transfer-sd15-controlnet`
  - `style-transfer-sd25-controlnet`

- **Metrics tracked:**
  - Training loss (per step and per epoch)
  - Learning rates (UNet + ControlNet)
  - Checkpoint saves (every 5 epochs)

## Checkpoints

Saved every 5 epochs:
- `checkpoint-epoch-5/`
- `checkpoint-epoch-10/`
- `checkpoint-epoch-15/`
- `checkpoint-epoch-20/`
- `final/` (same as epoch 20)

Each checkpoint contains:
- LoRA weights (`unet_lora/` or transformer LoRA)
- ControlNet weights (`controlnet/` if applicable)
- Full pipeline for inference
